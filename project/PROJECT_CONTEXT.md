# Контекст проекта ParkSharingApp

## Обзор
ParkSharingApp - это мобильное веб-приложение для аренды парковочных мест, разработанное для Telegram WebApp. Приложение позволяет владельцам парковок сдавать свои места в аренду, а клиентам - находить и бронировать доступные парковочные места.

## Технологический стек

### Основные технологии
- **Vue 3** (Composition API) - основной фреймворк
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Leaflet.js** - карты и геолокация
- **Firebase Hosting** - хостинг приложения
- **Telegram WebApp API** - интеграция с Telegram

### Зависимости
- `leaflet` - карты
- `swiper` - слайдеры
- `@mobiscroll/javascript-lite` - календари и пикеры
- `vue-scroll-picker` - скролл-пикеры
- `vue-slider-component` - слайдеры

## Архитектура

### Структура проекта
```
src/
├── App.vue              # Главный компонент, управление состоянием и навигацией
├── components/          # Переиспользуемые компоненты
├── views/               # Экраны приложения
├── services/            # Сервисы (mockAuth, featureToggles)
├── data/                # Моковые данные
├── assets/              # Статические ресурсы
├── types/               # TypeScript типы
└── style.css            # Глобальные стили
```

### Управление состоянием
- Централизованное состояние через `ref` в `App.vue`
- Навигация через `stage` ref (система экранов)
- Локальное состояние в компонентах через Composition API

### Навигация
Система экранов управляется через `stage` ref в `App.vue`. Каждый экран соответствует определенному значению типа `Stage`.

## Основные функции

### Для клиентов
- Поиск парковочных мест на карте
- Просмотр деталей парковочного места
- Бронирование с выбором дат и времени
- Управление автомобилями
- Управление платежными картами
- Чат с владельцами
- Просмотр активных бронирований

### Для владельцев
- Сдача парковочного места в аренду
- Настройка доступности (почасовая/посуточная/помесячная)
- Управление ценами
- Подтверждение/отклонение запросов на бронирование
- Чат с клиентами

## Особенности реализации

### Telegram WebApp интеграция
- Использование `window.Telegram?.WebApp` API
- Обработка BackButton
- Интеграция с Telegram UI

### Карты
- Leaflet для отображения карт
- Кастомные иконки маркеров
- Обратное геокодирование через Nominatim API
- Интерактивный выбор местоположения

### Аутентификация
- Mock-система аутентификации (`mockAuth.ts`)
- Тестовые пользователи для разработки
- Верификация через SMS-коды (мок)

### Стилизация
- Scoped CSS в компонентах
- Адаптивный дизайн
- Поддержка safe-area-inset для iOS
- Использование CSS Grid и Flexbox
