# Логика аренды парковочных мест (Rent Logic)

## Обзор
Документ описывает полную логику работы приложения для аренды парковочных мест, включая процесс сдачи места владельцем и процесс бронирования клиентом.

---

## Процесс сдачи места (Rent Out)

### Экраны процесса
1. **RentOutMapScreen** - выбор адреса на карте
2. **RentOutScreen** - заполнение формы сдачи места
3. **RentOutSuccessScreen** - подтверждение успешной публикации

### Навигация
- **Вход:** Кнопка "Сдать место" на главном экране → `openRentFromHome()` → `stage = 'rent'`
- **Альтернативный вход:** Кнопка "Найти парковку" → `openSearchFromHome()` → `stage = 'rent-map'` (открывает карту для выбора адреса)

### RentOutScreen - Форма сдачи места

#### Обязательные поля
1. **Адрес парковки** (`address`)
   - Можно ввести вручную или выбрать на карте
   - При клике "Выбрать адрес на карте" → `@open-map` → переход на `RentOutMapScreen`
   - Адрес синхронизируется между экранами через `selectedAddress` prop

2. **Типы аренды** (минимум один должен быть выбран)
   - Почасовая аренда (`hourlyRent`)
   - Посуточная аренда (`dailyRent`)
   - Помесячная аренда (`monthlyRent`)

3. **Стоимость аренды** (для каждого выбранного типа)
   - За час (`pricePerHour`) - обязательна, если `hourlyRent = true`
   - За сутки (`pricePerDay`) - обязательна, если `dailyRent = true`
   - За месяц (`pricePerMonth`) - обязательна, если `monthlyRent = true`

#### Опциональные поля
1. **Ограничения по типу автомобиля** (`vehicleTypes`)
   - Легковой / Кроссовер
   - Фургон/Минивэн
   - Грузовик
   - Можно выбрать несколько типов

2. **Фотографии места** (`photos`)
   - Загрузка через `<input type="file" accept="image/*" multiple>`
   - Можно загрузить несколько фотографий

3. **Период доступности**
   - **Постоянная доступность** (`permanentAvailability`)
     - Если включена → место доступно всегда
     - Если выключена → настраивается календарный период

4. **Календарный период доступности** (только если `permanentAvailability = false`)
   - **Для почасовой аренды** (когда только `hourlyRent = true`):
     - Одно поле даты (`fromDate`)
     - Дни недели (`selectedDays`) - выбор из: Пн, Вт, Ср, Чт, Пт, Сб, Вс
     - Время доступности:
       - С времени (`fromTime`) - формат `HH:mm`
       - До времени (`toTime`) - формат `HH:mm`
   
   - **Для помесячной аренды** (когда `monthlyRent = true`):
     - С даты (`fromDate`) - формат `YYYY-MM-DD`
     - По дату (`toDate`) - формат `YYYY-MM-DD`
     - Без времени
   
   - **Для других типов аренды** (посуточная или комбинации):
     - С даты (`fromDate`)
     - По дату (`toDate`)
     - Время доступности:
       - С времени (`fromTime`)
       - До времени (`toTime`)

5. **Особенности места** (`features`)
   - Крытая парковка
   - Охрана
   - Электрозарядка
   - Парковка во дворе
   - Частная территория
   - Можно выбрать несколько

6. **Описание** (`description`)
   - Текстовое описание места

### Валидация формы

#### Условия для отправки (`canSubmit`)
```typescript
const canSubmit = computed(() => {
  const hasAddress = address.value.trim() !== ''
  
  // Проверяем, что для каждого активного типа аренды заполнена стоимость
  const hourlyPriceValid = !hourlyRent.value || pricePerHour.value.trim() !== ''
  const dailyPriceValid = !dailyRent.value || pricePerDay.value.trim() !== ''
  const monthlyPriceValid = !monthlyRent.value || pricePerMonth.value.trim() !== ''
  
  // Проверяем, что хотя бы один тип аренды выбран
  const hasRentType = hourlyRent.value || dailyRent.value || monthlyRent.value
  
  return hasAddress && hasRentType && hourlyPriceValid && dailyPriceValid && monthlyPriceValid
})
```

#### Правила валидации
1. Адрес обязателен
2. Хотя бы один тип аренды должен быть выбран
3. Для каждого выбранного типа аренды должна быть указана стоимость
4. Стоимость должна содержать только цифры (символ ₽ добавляется автоматически)

### Обработка ввода цены

#### Фильтрация ввода
- Разрешены только цифры
- Символ ₽ удаляется автоматически при вводе
- Поддерживается вставка из буфера обмена (только цифры)

#### Отображение цены
- При отображении добавляется символ ₽: `value + '₽'`
- При вводе символ ₽ удаляется

### Обработка отправки

#### Процесс отправки
1. Проверка `canSubmit`
2. Установка `isSubmitting = true`
3. Симуляция отправки (2 секунды)
4. Проверка тестового пользователя:
   - Если `currentUser.phone === '+79991234567'` → показывается экран ошибки
   - Иначе → `@success` → переход на `RentOutSuccessScreen`

#### Обработка ошибок
- При ошибке показывается `RentOutErrorScreen`
- Кнопка "Попробовать снова" → `handleRetry()` → `showError = false`

## Процесс бронирования (Booking)

### Экраны процесса
1. **SearchScreen** / **RentOutMapScreen** - поиск и выбор места
2. **ParkingSpotDetailsScreen** - детали парковочного места
3. **BookingDatesScreen** - выбор дат, времени и типа аренды
4. **BookingSummaryScreen** - подтверждение бронирования
5. **BookingConfirmationScreen** - успешное бронирование
6. **BookingErrorScreen** - ошибка бронирования

### Навигация

#### Поиск места
- **SearchScreen**: Список доступных парковок
- **RentOutMapScreen**: Карта с маркерами парковок
- При клике на место → `handleReserve(parking)` → `stage = 'details'`

#### Выбор дат и времени
- Из `ParkingSpotDetailsScreen` → `@select-dates` → `stage = 'booking-dates'`
- На `BookingDatesScreen`:
  - Выбор типа аренды
  - Выбор дат и времени
  - Выбор автомобиля
  - Выбор платежной карты
  - Кнопка "Забронировать" → `@book` → передача данных бронирования

#### Подтверждение
- Из `BookingDatesScreen` → `@book` → `handleBookingDatesBook()` → `stage = 'summary'`
- На `BookingSummaryScreen` → `@confirm` → `handleBookingConfirmation()` → `stage = 'active'` или `'booking-confirmation'`

### BookingDatesScreen - Выбор параметров бронирования

#### Типы аренды (`rentalType`)
- `'hourly'` - Почасовая
- `'daily'` - Посуточная
- `'monthly'` - Помесячная

#### Выбор дат и времени

**Для почасовой аренды (`rentalType === 'hourly'`):**
- Одно поле даты (`startDate`)
- Время начала (`startTime`) - формат `HH:mm`
- Время окончания (`endTime`) - формат `HH:mm`
- **Валидация:**
  - `endDate` автоматически устанавливается равным `startDate`
  - Если `startTime > endTime`, то `endTime = startDate`
  - Минимальная дата: сегодня (`min="today"`)

**Для помесячной аренды (`rentalType === 'monthly'`):**
- С даты (`startDate`)
- По дату (`endDate`)
- Без времени
- **Валидация:**
  - `endDate` не может быть раньше `startDate`
  - Минимальная дата: сегодня

**Для посуточной аренды (`rentalType === 'daily'`):**
- С даты (`startDate`)
- По дату (`endDate`)
- Время начала (`startTime`)
- Время окончания (`endTime`)
- **Валидация:**
  - Если `startDate === endDate` и `startTime > endTime`, то `endTime = startTime`
  - Минимальная дата: сегодня

#### Расчет продолжительности (`duration`)

**Для помесячной аренды:**
- Вычисляется разница в месяцах и днях
- Формат: "X месяцев Y дней" или "X месяца Y дня" (с правильными склонениями)

**Для почасовой и посуточной:**
- Вычисляется разница в часах и минутах
- Формат: "X часов Y минут" или "X дней Y часов" (с правильными склонениями)

#### Расчет стоимости (`totalPrice`)

**Для почасовой аренды:**
```typescript
const pricePerHour = parseInt(location.priceHour.replace('₽/ч', '').trim())
const start = new Date(`${startDate.value}T${startTime.value}`)
const end = new Date(`${endDate.value}T${endTime.value}`)
const diffMs = end.getTime() - start.getTime()
const diffHours = Math.ceil(diffMs / (1000 * 60 * 60)) // Округляем вверх
const total = pricePerHour * diffHours
return `₽${total}`
```

**Для посуточной аренды:**
- Используется фиксированная цена из `location.priceDay`

**Для помесячной аренды:**
- Используется фиксированная цена из `location.priceMonth`

#### Выбор автомобиля

**Требования:**
- Автомобиль обязателен для бронирования
- Если автомобиля нет → кнопка "Добавить автомобиль" → `@add-car` → `stage = 'rent-add-car'`
- Если автомобиль есть → кнопка "Изменить автомобиль" → `@change-car` → `stage = 'car-selection'`

**Отображение:**
- Бренд и модель
- Цвет (если указан)
- Номер и регион

#### Выбор платежной карты

**Требования:**
- Платежная карта обязательна для бронирования
- Если карты нет → кнопка "Выбрать карту" → `@change-payment-card` → переход на экран выбора карты
- Если карта есть → кнопка "Изменить карту" → `@change-payment-card`

**Отображение:**
- Тип карты (VISA, MasterCard, МИР)
- Последние 4 цифры
- Имя держателя

#### Валидация бронирования

**Условие для кнопки "Забронировать" (`canBook`):**
```typescript
const canBook = computed(() => {
  return !!(props.userCar && props.paymentCard)
})
```

**Данные бронирования:**
```typescript
{
  address: string
  startDate: string      // Формат: 'YYYY-MM-DD'
  endDate: string        // Формат: 'YYYY-MM-DD'
  startTime: string      // Формат: 'HH:mm'
  endTime: string        // Формат: 'HH:mm'
  rentalType: 'hourly' | 'daily' | 'monthly'
}
```

### BookingSummaryScreen - Подтверждение бронирования

#### Отображаемая информация
1. Название и адрес парковки
2. Дата и время бронирования
3. Номер места
4. Способ оплаты
5. Детализация стоимости:
   - Стоимость аренды (рассчитывается на основе типа и продолжительности)
   - Сервисный сбор (10% от стоимости аренды)
   - Итого к оплате

#### Расчет стоимости
```typescript
const priceNumeric = Number(parking.pricePerHour.replace(/\D/g, ''))
const serviceFee = Math.round(priceNumeric * 0.1)  // 10% комиссия
const total = priceNumeric * 2 + serviceFee  // Пример: 2 часа
```

**Примечание:** В текущей реализации используется фиксированная стоимость для примера. В реальной версии расчет должен основываться на выбранных параметрах бронирования.

## Типы аренды - Детальные правила

### Почасовая аренда (`hourly`)

#### Особенности
- Минимальный период: 1 час
- Округление: всегда вверх до целых часов
- Ограничения:
  - Дата начала и окончания должны быть одинаковыми
  - Время окончания не может быть раньше времени начала
  - Минимальная дата: сегодня

#### Расчет стоимости
- Формула: `цена_за_час × количество_часов`
- Количество часов округляется вверх: `Math.ceil((end - start) / (1000 * 60 * 60))`

#### Отображение продолжительности
- Меньше часа: "X минут"
- Меньше суток: "X часов" или "X часов Y минут"
- Больше суток: "X дней Y часов"

### Посуточная аренда (`daily`)

#### Особенности
- Оплата за полные сутки, даже если приехали и уехали раньше
- Можно выбрать период (несколько дней)
- Время начала и окончания учитывается для расчета продолжительности

#### Расчет стоимости
- Формула: `цена_за_сутки × количество_суток`
- Количество суток рассчитывается на основе дат и времени

#### Отображение продолжительности
- Формат: "X дней Y часов" или "X дней"

### Помесячная аренда (`monthly`)

#### Особенности
- Предоплата производится за один месяц
- Далее списание по месяц
- Неполный месяц оплачивается полностью
- Без указания времени (только даты)

#### Расчет стоимости
- Формула: `цена_за_месяц × количество_месяцев`
- Неполный месяц считается как полный

#### Отображение продолжительности
- Формат: "X месяцев Y дней" или "X месяцев"

## Важные правила и ограничения

### 1. Валидация дат
- Минимальная дата для бронирования: сегодня
- Дата окончания не может быть раньше даты начала
- Для почасовой аренды даты начала и окончания должны совпадать

### 2. Валидация времени
- Время окончания не может быть раньше времени начала (для одной даты)
- Формат времени: `HH:mm` (24-часовой формат)

### 3. Обязательные поля для бронирования
- Автомобиль (`userCar`)
- Платежная карта (`paymentCard`)
- Дата и время бронирования
- Тип аренды

### 4. Обязательные поля для сдачи места
- Адрес
- Хотя бы один тип аренды
- Стоимость для каждого выбранного типа аренды

### 5. Расчет стоимости
- Почасовая: округление вверх до целых часов
- Посуточная: оплата за полные сутки
- Помесячная: неполный месяц = полный месяц
- Сервисный сбор: 10% от стоимости аренды

### 6. Обработка ошибок
- Тестовый пользователь `+79991234567` всегда получает ошибку при сдаче места
- Ошибки бронирования обрабатываются через `BookingErrorScreen`

## Примечания для разработчиков

1. **Всегда проверяйте валидность данных** перед отправкой формы
2. **Используйте правильные форматы дат и времени** (`YYYY-MM-DD` для дат, `HH:mm` для времени)
3. **Округляйте стоимость вверх** для почасовой аренды
4. **Следуйте правилам валидации** для каждого типа аренды
5. **Тестируйте все комбинации типов аренды** (только почасовая, только посуточная, только помесячная, комбинации)
6. **Учитывайте особенности каждого типа аренды** при расчете стоимости и продолжительности
7. **Проверяйте наличие обязательных данных** (автомобиль, карта) перед переходом к бронированию
